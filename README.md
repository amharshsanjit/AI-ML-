# AI & Intelligent Agents – Prolog Practicals

This repository contains the complete Prolog practical programs for **Unit 1: Introduction to AI and Intelligent Agents**.

The programs demonstrate important concepts of **Artificial Intelligence, Knowledge Representation, Rule-Based Reasoning, Recursion, List Processing, and Inference in Prolog**.

---

## 📚 Experiments

| Experiment | Practical / Topic |
|------------|-------------------|
| **Exp 1** | Student-Course Knowledge Base |
| **Exp 2** | Arithmetic Operations, Factorial & Fibonacci |
| **Exp 3** | List Operations |
| **Exp 4** | College Timetable Knowledge Base |
| **Exp 5** | Student Performance Analysis |
| **Exp 6** | Travel Route Recommendation System |

---
